## Uso
Abrir index.html con internet. La página carga GeoGebra Clásico y ejecuta los comandos de cada ejercicio. Si falla un comando, abrir GeoGebra Clásico en inglés, activar las vistas 2D y 3D y pegar las líneas del archivo correspondiente en comandos/. Guardar cada construcción como .ggb y subirla al repositorio.

## Publicación
Subir el contenido de esta carpeta a un repositorio público. En Settings > Pages seleccionar Deploy from a branch, main y / (root). Comprobar los tres ejercicios desde el enlace publicado.

## Pendientes
Probar la integración en un navegador con internet, guardar los GGB, tomar capturas reales, grabar el video y añadir los enlaces al informe. No requiere cuenta para visitar la página.
